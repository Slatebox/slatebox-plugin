# Slatebox plugin

Slatebox is an open source visual intelligence platform where you can invite any AI via MCP to collaborate with you and your team.

This plugin gives Claude seven skills and three commands for drawing and reading slates with the hosted Slatebox MCP server at `https://app.slatebox.com/mcp`:

- Skills: make a mind map, make a flowchart (from steps or Mermaid), plan a project as a Gantt chart, add a smart board, read and summarise a slate, present a slate, ask the Slatebox agent.
- Commands: `/slatebox:mindmap`, `/slatebox:flowchart`, `/slatebox:plan`.

Sign in to Slatebox when Claude asks; every call acts as you and reaches only the slates you can open.

- Docs: https://docs.slatebox.com/developers/slateboxapi/mcp/
- Support: https://slatebox.com/contact/
- Privacy: https://slatebox.com/privacy/
